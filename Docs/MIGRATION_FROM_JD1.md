# Passaggio da JD1 / Moving from JD1

## Italiano

1. Nel vecchio Hub esporta la configurazione. Preferisci ZIP se disponibile, perché il solo file di configurazione non include le immagini personali.
2. Conserva il backup e chiudi completamente JD1, anche nell'area di notifica. JD1 e JD2 non possono usare contemporaneamente la stessa COM.
3. Installa JD2 e il firmware richiesto dalla sua release. Il nuovo nome della repository separa la distribuzione: il controllo aggiornamenti del vecchio JD1 non implica il passaggio automatico a JD2.
4. All'avvio verifica se l'attivazione viene riconosciuta. Se JD2 presenta la richiesta, usa il modulo integrato e attendi il codice gratuito. Non cancellare manualmente i dati di attivazione.
5. Collega il dispositivo con lo stick centrato. Se non viene identificato, ricontrolla la compatibilità firmware.
6. Verifica le impostazioni eventualmente già presenti prima di importare. Se necessario importa il backup e controlla percorsi locali, scorciatoie, colori e icone. I profili precedenti senza Page 2 vengono caricati con Page 2 vuota.
7. Mouse move e Orbital sono esclusivi globalmente: mantieni una sola istanza di una delle due modalità tra le due pagine.
8. Configura Bambu Cloud separatamente. Il token non è trasferito dai pacchetti di configurazione.
9. Prova le azioni e salva un nuovo backup dopo la verifica.

La cartella dati dell'Hub può essere condivisa tra versioni: il backup va eseguito prima del primo avvio di JD2. La compatibilità di un profilo precedente non garantisce che percorsi e azioni siano ancora adatti al PC attuale.

## English

Export the JD1 configuration first, preferably as a ZIP package with custom icons. Keep the backup and close JD1 completely before connecting JD2. The repositories are separate; the old Hub's update check does not automatically migrate to JD2.

Install JD2 with the firmware required by its release. If an existing activation is accepted, continue; otherwise request a free code through JD2. Check any settings already loaded, then import the backup if needed and verify all assignments. Older profiles without Page 2 load with an empty second page. Only one Mouse move or Orbital assignment is allowed across both pages.

Sign in to Bambu Cloud separately: account tokens are not part of configuration packages. Test the actions and export a new backup. Data folders may be shared between Hub versions, so make the initial backup before launching JD2.
