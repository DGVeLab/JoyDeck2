# Moving from JD1

Export the JD1 configuration first, preferably as a ZIP package with custom icons. Keep the backup and close JD1 completely before connecting JD2. The repositories are separate; the old Hub's update check does not automatically migrate to JD2.

Install JD2 with the firmware required by its release. If an existing activation is accepted, continue; otherwise request a free code through JD2. Check any settings already loaded, then import the backup if needed and verify all assignments. Older profiles without Page 2 load with an empty second page. Only one Mouse move or Orbital assignment is allowed across both pages.

Sign in to Bambu Cloud separately: account tokens are not part of configuration packages. Test the actions and export a new backup. Data folders may be shared between Hub versions, so make the initial backup before launching JD2.
