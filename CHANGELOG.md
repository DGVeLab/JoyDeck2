# Changelog

## 2.2.7 — Initial JD2 publication package

This entry describes the application version used to prepare the initial public distribution. The release date and downloadable assets are recorded in GitHub Releases when published.

- Eight configurable joystick directions with RGB feedback and overlay icons.
- Temporary Page 2 with eight additional directions and a shared global trigger.
- Application/file and link launchers, keyboard presets and macros, key Hold and Spam, HTTP requests and Windows actions.
- Mouse move, Orbital, Media Control and Spotify modes.
- Memory and Reaction mini games with saved high scores.
- Optional Bambu Cloud monitoring for progress, temperatures, fans and status, with printer selection per direction.
- Configuration packages with custom icons, and remembered Mini Game and Bambu monitor window positions.

Firmware compatibility and package-specific installation notes belong to the matching release. Hub and firmware versions are independent.
