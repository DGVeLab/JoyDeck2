# Security reporting

Send security vulnerabilities and accidental exposure of credentials privately to **dgvelab@gmail.com**. Use the subject **JoyDeck 2 security report** and include the affected version, impact and reproducible steps.

Do not include working passwords, access tokens, activation codes or other users' data. Do not open public issues containing sensitive details.

Use the latest published release when checking a potential issue. Security reports are reviewed as time permits; there is no guaranteed response time.
