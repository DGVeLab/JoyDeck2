10. OPTIONAL BAMBU CLOUD INTEGRATION
The user may connect a Bambu Lab account to monitor associated printers. JoyDeck 2 Hub communicates directly with Bambu Lab services over encrypted HTTPS and MQTT/TLS connections. The feature receives printer reports and sends a limited request for a complete telemetry report when monitoring starts or needs to recover current data. These report requests do not change printer settings or control heating, movement or printing; no printer control commands are sent.

The access token, region, cloud user identifier and any available expiry information are stored only on the user's computer in a local session file, encrypted using Windows protection associated with the current user (DPAPI CurrentUser). This enables subsequent use without signing in every time. The Bambu account password is not stored. The email address and verification code entered for sign-in are sent directly to Bambu Lab; they are not stored in the local session file.

DGVeLab does not receive, collect or store the Bambu access token on its systems and has no remote mechanism through activation, support or this integration to view it. The token is excluded from JoyDeck configuration files, profile backups and application logs. Printer reports and graph history are processed locally; the Bambu monitoring feature does not forward them to DGVeLab systems. Graph history is held only in memory for the monitoring session and is cleared when monitoring ends.

The local session remains stored until the user disconnects the account, replaces it through a new sign-in, or removes the application's local data. The token's validity is controlled by Bambu Lab: it can expire, be revoked or be rejected before its indicated expiry. A new sign-in is required when necessary. Disconnecting the account in Cloud settings deletes the locally stored token and clears the active local session; it does not revoke all sessions of the Bambu account.

Bambu Lab receives the information required to authenticate the account and operate its cloud service, under Bambu Lab's own terms and privacy notice available on its official website. DGVeLab does not operate that service or determine its availability or token lifetime. Local encryption does not guarantee protection from parties who control the user's PC or Windows session. Copying the token file to another computer or Windows user is not a supported account-transfer method.

The 180-day retention period in section 5 applies to software activation requests, not to the Bambu token or local graph history.
